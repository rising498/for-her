SORRY WEBSITE — GRAPHICAL VERSION 💗

1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use Live Server.
4. Do not separate the images folder from index.html.

Files:
- index.html: all three pages and text
- style.css: graphical design, responsive layout, animations
- script.js: button and page interactions
- images/: your 3 uploaded photos

The “Not accept” button dodges the cursor/tap as a playful effect. The actual choice to forgive should always be hers.
